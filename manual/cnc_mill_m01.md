## Tool wear

Symptoms: rising spindle torque, poor surface finish, tool wear above 200 minutes.
Fix: replace the main end mill, part EM-1004 (carbide end mill 10 mm 4-flute).
Steps: 1. Stop the spindle and lock out the machine. 2. Remove the tool holder. 3. Fit the new end mill and set the tool length offset. 4. Run a test cut.
Repair time: 30 minutes. Required skill: cnc_tooling.

## Finishing tool

The finishing end mill, part EM-1006 (carbide end mill 6 mm 2-flute), is only used for finishing passes. Replace it when finishing quality drops.

## Coolant pump

Replace pump CP-220 if coolant flow drops. Required skill: mechanical.
